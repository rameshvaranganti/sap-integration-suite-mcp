# Security policy

See [detailed security documentation](docs/SECURITY.md) for deployment controls, the threat model and reporting guidance.

Version 0.1.x receives security fixes. Do not report credentials or customer data in public issues. Use the repository's GitHub **Security → Report a vulnerability** private reporting feature when enabled. Repository maintainers must enable private vulnerability reporting before public release. If it is unavailable, ask for a private reporting channel without disclosing exploit details in a public issue.
